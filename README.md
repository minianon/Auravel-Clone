# auravel - breakoutAI Round 1 Challenge

This repository contains the code for the Round 1 technical assessment for the Frontend Engineer Intern role at breakoutAI. The goal was to clone a website with pixel-perfect accuracy, full responsiveness, and all original animations within a 48-hour timeframe.

## ✅ Core Focus Areas

This project was built with a primary focus on the key requirements of the challenge:

*   **Design Fidelity:** Aiming for a pixel-perfect replication of the original site's UI and layout.
*   **Responsiveness:** Ensuring a seamless and fully responsive experience across desktop, tablet, and mobile breakpoints.
*   **Animations & Interactions:** Replicating all key animations, hover states, and scroll-triggered events to match the original user experience.
*   **Performance:** Keeping the final build lightweight with optimized assets.

## ⚙️ Running the Project Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/TuShArBhArDwA/Auravel-Clone.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd Auravel-Clone
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Start the development server:**
    ```bash
    npm run dev
    ```

The application will be available at `http://localhost:5173`.
